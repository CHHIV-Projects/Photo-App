# 1. Purpose

Turn the proven Windows Helper backend into normal Photo Organizer usage.

12.66.1–12.66.6 established:

Windows Helper trust
→ Source identity/readiness
→ inventory
→ acquisition
→ verified receiving
→ common Source Intake
→ Vault / Asset / Provenance
→ unchanged-repeat idempotency

12.66.7 must now make the user experience:

Photo Organizer
→ Ingestion
→ select Windows Source
→ Run Ingestion

The Windows Helper remains technically separate software on Windows, but it should become underlying infrastructure rather than a separate ingestion utility the Product Owner manually operates.

This milestone has two primary deliverables:

1. normal Ingestion UI integration for the proven Windows Local workflow;
2. a packaged, per-user, on-demand Windows Helper lifecycle that does not require manually opening PowerShell and running `serve` during ordinary use.

Do not redesign provider, acquisition, Source Intake, Vault, Asset, or Provenance architecture.
