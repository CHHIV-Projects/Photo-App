# 9. Persisted Source Identity

+

+
Profile-relative root

The resulting current Windows runtime path is provider-native runtime evidence.

It is not a Linux mount.

If existing persistence would require permanently rewriting the Profile whenever a drive letter changes:

STOP AND ESCALATE before altering the model.
