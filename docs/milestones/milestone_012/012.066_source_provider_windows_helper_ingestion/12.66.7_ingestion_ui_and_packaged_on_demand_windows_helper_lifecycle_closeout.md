The backend exposes a redacted UI facade over the existing identity probe, inventory, acquisition, bridge, and Source creation plan/confirm services. The frontend routes by an explicit provider discriminator and presents Create Source, concise Source selection, on-demand readiness, bounded candidate review, one Start Ingestion confirmation, progress, and accurate repeat results.
