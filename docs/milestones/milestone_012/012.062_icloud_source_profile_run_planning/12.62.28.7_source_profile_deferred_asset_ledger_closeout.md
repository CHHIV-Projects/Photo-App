## Schema/Model Changes

Added:

```text
source_profile_deferred_assets
source_profile_deferred_asset_events
```

Current-state uniqueness:

```text
source_profile_id + remote_identity_basis + remote_identity + deferred_category
```

The schema sync is additive/idempotent and is ensured from startup and iCloud backfill schema setup.

## Service Behavior

The iCloud inventory scan now records all safely mappable non-eligible rows. Adjusted-resource rows are guaranteed.

Category mapping:

```text
unsupported_adjusted_resource -> adjusted_resource_deferred
identity_ambiguous=true with no clearer reason -> ambiguous_metadata_deferred
non-empty non-adjusted unsupported_reasons_json -> unsupported_metadata_deferred
eligibility_state=pending_classification -> pending_classification_deferred
fallback -> unknown_deferred
```

Eligible rows are not recorded as active deferred rows. If a previously deferred identity is observed again as eligible, its active deferral is closed as `no_longer_deferred`.

## Event/History Behavior

Events append for:

```text
first_deferred
reason_changed
classification_changed
```

Unchanged repeat observations do not append duplicate events.

## JSON Report Behavior

Inventory scans write safe reports under:

```text
storage/logs/deferred_asset_reports/
```

Reports include total/new/changed/unchanged/resolved counts, category/reason summaries, adjusted-resource counts, and safe sample rows.

## API/Status Behavior

Added iCloud backfill status fields:

```text
deferred_current_count
deferred_adjusted_resource_count
deferred_ambiguous_count
deferred_unsupported_count
deferred_new_since_last_scan_count
deferred_changed_since_last_scan_count
```

Added read-only endpoint:

```text
GET /api/admin/source-profiles/{source_id}/deferred-assets
```

It supports bounded safe filtering by `limit`, `category`, `reason_code`, and `state`.
