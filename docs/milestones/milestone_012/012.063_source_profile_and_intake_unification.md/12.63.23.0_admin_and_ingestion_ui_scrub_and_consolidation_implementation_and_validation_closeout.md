## 5. Source Definition

For this UI, `Source` means a saved Source Profile.

Distinctions preserved:

- Source Profile: operator-facing saved Source configuration.
- Source Endpoint: durable device/share/provider/media identity.
- Observed Path: current access evidence such as a drive letter, mount path, or UNC path.
- Source Intake Run: one ingestion execution against a Source Profile.
