# 18. Decision Framework

The closeout must classify the result into one or more of these categories.

## A. Windows recognition defect only

Use when:

- fingerprints are deterministic when produced;
- the main failure is that Windows evidence intermittently fails to classify the drive as Optical.

Recommend the smallest provider-recognition correction.

## B. Fingerprint serialization nondeterminism

Use when:

- identical normalized inputs produce different serialized order or hash results.

Recommend deterministic ordering/serialization while preserving v1 compatibility where possible.

## C. Unstable metadata included in v1

Use when:

- repeated probes differ because a field such as timestamp or directory metadata changes without media-content change.

Recommend whether v1 can be corrected compatibly or whether v2 is required.

## D. Enrollment/verification path divergence

Use when:

- Source Creation and later verification do not use identical roots, options, or manifest rules.

Recommend unifying call paths.

## E. Actual media-state difference

Use when:

- the disc’s filesystem metadata or content genuinely changed between enrollment and verification.

Explain whether current blocking is correct.

## F. Inconclusive environmental issue

Use only when controlled diagnostics cannot reproduce or isolate the problem.

State precisely what evidence is still missing.
