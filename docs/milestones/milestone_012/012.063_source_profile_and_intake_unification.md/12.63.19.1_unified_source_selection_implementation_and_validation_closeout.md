## Changed-drive-letter discovery correction

The original closeout was misleading: it validated changed-drive-letter behavior only when alternate observed-path evidence was already stored. That did **not** prove discovery of a new, never-before-observed drive letter.

This correction adds bounded read-only mounted-volume discovery for Windows filesystem volumes:

- Function: `enumerate_windows_mounted_volume_candidates()`
- Provider call:

```powershell
Get-Volume -ErrorAction SilentlyContinue |
  Where-Object DriveLetter |
  Select-Object DriveLetter,DriveType,UniqueId,Path,FileSystemType,FileSystemLabel |
  ConvertTo-Json -Compress -Depth 3
```

Behavior:

- Windows-only; non-Windows returns no mounted-volume candidates.
- Bounded timeout: `5.0` seconds.
- Enumerates currently mounted logical volumes only.
- Extracts Volume GUID evidence from `UniqueId` or `Path`.
- Converts the Volume GUID to the existing durable `volume_guid_fingerprint`.
- Compares the mounted candidate fingerprint to the selected `SourceEndpoint.identity_fingerprint_hash`.
- Probes only matching mounted candidates.
- Reconstructs Source Root as current matched endpoint root + `endpoint_relative_root`.
- Does not mutate drive letters or mount points.
- Does not scan directory trees.
- Does not use A-Z drive probing.
- Does not create/update observed-path rows.
- Does not mutate Source Profiles or Source Endpoints.

- This is limited to Source Selection's read-only usability classification; it does not change run-launch safety semantics.

- This keeps Source Selection read-only while allowing verified endpoint-linked Removable/External/NAS-style probe results to select normally.

## Source Selection API

Route:

```http
POST /api/admin/source-selection/select
```

Request contains only:

```json
{
  "source_profile_id": 90
}
```

The backend derives source type, endpoint, root, provider, workflow kind, and identity details. Frontend-submitted identity/root/provider fields are forbidden.

Business outcomes return HTTP 200:

- `selected + available`
- `not_selected + unavailable`
- `not_selected + needs_attention`

Missing Source Profile returns HTTP 404.
