# 12.63.16 Ingestion Workbench Source Picker UI Closeout

## 1. Scope Completed

Implemented the first frontend step for the simplified Ingestion Workbench source picker.

The Ingestion page now has a new source-focused workbench section near the top of the page. It lets the operator:

```text
pick an operator-facing source type
search source profiles
select a source
toggle inactive / legacy visibility
review a lightweight selected-source summary
open the existing Details drawer
open the existing Manage drawer
```

This milestone did not implement the selected-source workflow panel. Check Readiness, Run Intake, and iCloud Refresh / Prepare / Import / Resume remain in their existing locations for now.

## 4. Source Type Selector Summary

Visible source type categories:

```text
Local
External
NAS
iCloud
Advanced / Legacy
```

Frontend-only presentation mapping:

```text
local_folder + non-UNC root path -> Local
local_folder + UNC root path -> NAS
external_drive -> External
cloud_export + iCloud/cloud_provider=icloud/acquisition_method=icloudpd -> iCloud
scan_batch -> Advanced / Legacy
other -> Advanced / Legacy
non-iCloud cloud_export -> Advanced / Legacy
unknown/unmapped -> Advanced / Legacy
```

`Advanced / Legacy` also acts as a catch-all when `Show inactive / legacy sources` is enabled, so inactive/test/archived/deprecated sources can be found for audit/navigation.

No persisted source type migration was performed.

## 5. Source Selector / Search Summary

The source selector uses the loaded Source Profile summaries and filters locally.

The page now fetches all Source Profiles once:

```text
getSourceProfiles({ status: "all" })
```

Then it derives:

```text
registry rows from the existing Status filter
workbench rows from source type + search + inactive/legacy toggle
```

Search matches safe fields:

```text
source label
source root path
managed staging path
cloud provider
acquisition method
masked account username
path/provider hint
```

The default workbench view shows active sources only.

## 6. Selected Source Summary

The selected-source summary displays:

```text
Source label
Profile status
Operator-facing type
Stored source type
Path / provider hint
Cloud provider, when applicable
Identity status
Endpoint ID, when available
Readiness status, if already checked in the current Details drawer state
Workflow placeholder
```

Identity display:

```text
iCloud -> Provider-specific
endpoint_id present -> Enrolled
endpoint_id missing -> Not enrolled
```

Workflow placeholder behavior:

```text
Filesystem sources:
  Filesystem workflow actions will move here next: Check Readiness and Run Intake.

iCloud sources:
  iCloud workflow actions remain in the iCloud Intake panel for now: Refresh / Prepare and Import / Resume.

Advanced / Legacy sources:
  These sources are retained for history, diagnostics, or unsupported workflows.
```

The `Details` and `Manage` buttons reuse the existing drawer handlers. No duplicate drawer logic was added.
