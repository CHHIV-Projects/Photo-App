# 5. Locked Architecture

## 5.1 Provider classes

The accepted architecture is:

```text
Mounted Source Provider
Windows Source Helper Provider
Cloud Provider
```

This milestone implements only the Linux Mounted Source Provider repository seam.

Do not treat Linux as the universal filesystem provider.

Do not translate Windows paths into Linux paths.

Do not implement or design Windows Helper transport, lifecycle, pairing, or transfer.

iCloud remains unchanged.

---

## 5.2 Common ingestion authority

Mounted Source functionality ends at the existing Source Intake execution boundary.

Preserve:

```text
provider identity/readiness/access
→ verified Runtime Root
→ existing Source Intake
→ Vault
→ Asset/database
→ provenance
```

The Mounted provider must not:

- manage Vault files;

- create Assets directly;

- implement duplicate policy;

- persist provenance directly;

- implement Mounted-specific canonicalization;

- create a second ingestion engine.

Do not modify the 12.64 ingestion/Vault implementation unless repository reality exposes a direct contradiction.
