## 20. Deviations

- The repository's narrow persistent fetch refspec did not include `main`.
  Product Owner-approved explicit fetches refreshed only the required refs;
  persistent configuration was not changed.
- `git switch --track -c main origin/main` proved unusable because Git did not
  recognize explicitly fetched `origin/main` as trackable under that refspec.
- Two tracking-switch attempts rewrote the index/worktree to the old main tree
  before failing. In both cases `HEAD` and every committed ref remained intact;
  the index/worktree exactly matched `origin/main`, with no untracked or
  conflicted files. Each attempt was restored exactly from the accepted
  integration SHA before continuing.
- The first command blocks enabled `set -e` in the Product Owner's login shell,
  causing SSH to close when the switch failed. All later blocks ran in child
  shells so a failure could not close the connection.
- The Product Owner explicitly approved `git switch --no-track -c main
  origin/main`. No upstream was configured, and all pull/push operations named
  `origin main` explicitly.
- After the successful push, local `origin/main` remained stale because of the
  narrow refspec. The push itself had succeeded; no repeat push occurred. One
  approved bounded explicit fetch refreshed the verification ref.
- Git's fast-forward summary listed historical deployment documents as
  `create mode` because they existed on integration but not old main. The
  Product Owner paused the push, confirmed they are intended repository
  history, and explicitly resolved the concern before continuation.
- One backend socket check initially used the wrong filename and returned local
  `FileNotFoundError`. The exact tracked path, `broker.sock`, was then validated
  successfully; no runtime repair or retry mutation occurred.
- A nonessential local `sed` read stalled and was terminated without output or
  mutation. The necessary column names were obtained through a transaction-
  read-only schema query.
- The workspace patch helper remains unusable because its sandbox cannot
  configure loopback networking. This closeout was created using a non-staging
  unified `git apply` diff. No index operation was used.
